Technical Stack, Authenticity, and Freshness Standards
- Google Cloud Requirement: All submitted prototypes must be built primarily using the Google Cloud tech stack (e.g., Cloud Run, GCP, Firebase). Solutions built primarily on competing cloud infrastructure will be deemed ineligible and disqualified.
- Fresh Code Base (No Pre-existing Work): Submissions must consist exclusively of fresh code and original assets created during the official hackathon timeline. Pre-existing products, ongoing projects, or code developed prior to the official launch will be disqualified.
- Prototype & Deliverables: Participants must submit a working, end-to-end prototype. Mandatory submission artifacts include: a) A working deployed live URL (on Cloud Run/GCP/Firebase). b) A video demonstration strictly under three (3) minutes in length. c) A public GitHub repository containing the source code. d) A comprehensive presentation deck explaining the solution architecture and business case.
